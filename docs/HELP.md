# 도움말 문구 (5단계)

> 작성 · 수정: lead. 화면에 이 문구를 **그대로** 쓴다 (CLAUDE.md "문구는 그대로" 규칙을 이 문서에도 적용).
> [도움말]을 누르면 지금 화면의 도움말이 큰 글씨 창으로 뜬다 (PLAN 결정 47).

---

## 화면별 [도움말]

### ① 노래 가져오기 (`Main.html`)

**제목**: 노래를 가져오는 방법

1. 유튜브에서 넣고 싶은 노래 영상을 열어요.
2. 맨 위 주소창을 한 번 누르고, 마우스 오른쪽 버튼 → [복사]를 눌러요.
3. 이 화면으로 돌아와 [붙여넣기]를 누르면 주소가 들어가요.
4. [노래 불러오기]를 누르면 노래를 가져와요.

> 재생목록 주소는 넣을 수 없어요. 노래 영상 하나의 주소를 넣어 주세요. 20분이 넘는 영상도 가져올 수 없어요.

### ② 불러오는 중 · 노래를 만들고 있어요 (`Loading.html`)

**제목**: 기다리는 동안

1. 노래를 가져오거나 만드는 데 1분쯤 걸릴 수 있어요.
2. 이 창을 닫지 말고 기다려 주세요. 다 되면 저절로 다음 화면으로 넘어가요.
3. 그만두고 싶으면 [취소하고 돌아가기]를 누르세요.

### ③ 노래 다듬기 (`Edit.html`)

**제목**: 노래를 다듬는 방법

1. [잘라내기]: 노래의 앞부분이나 뒷부분을 잘라요.
2. [빠르기]: 노래를 빠르게 하거나 느리게 해요.
3. [노래 하나 더 붙이기]: 다른 노래를 뒤에 이어 붙여요. [위로] [아래로]로 순서를 바꾸고, [빼기]로 목록에서 빼요.
4. 잘못 바꿨으면 맨 위의 [되돌리기]를 누르세요. 바꾸기 전으로 돌아가요.
5. 다 고쳤으면 [다 됐어요, 저장하기]를 누르세요.

### ④ 한 곡 잘라내기 (`Trim.html`)

**제목**: 잘라내는 방법

1. 파란 부분만 남고, 회색 부분은 잘려 나가요.
2. [−5초] [+5초]를 누르거나, 파란 부분 양 끝의 손잡이를 마우스로 끌어서 시작과 끝을 옮겨요.
3. [남긴 부분 들어보기]를 눌러 잘 잘렸는지 들어 보세요.
4. 다 됐으면 [완료, 목록으로]를 누르세요. 바꾼 것은 바로 반영돼요.

### ⑤ 한 곡 빠르기 · ⑥ 모든 노래 빠르기 (`Speed.html`, `SpeedAll.html`)

**제목**: 빠르기를 바꾸는 방법

1. [느리게] [보통] [빠르게] 중에 하나를 누르세요.
2. 조금씩 바꾸고 싶으면 [− 느리게] [+ 빠르게]를 누르세요.
3. [목소리 높낮이는 그대로 두기]를 켜 두면 빨라져도 목소리가 높아지지 않아요.
4. 모든 노래 빠르기는 [모든 노래에 적용하기]를 눌러야 바뀌어요.

### ⑦ 저장 완료 (`Done.html`)

**제목**: 저장하는 방법

1. [내 컴퓨터에 저장하기]를 누르면 노래 파일이 컴퓨터에 저장돼요.
2. [들어보기]로 저장하기 전에 들어 볼 수 있어요.
3. 다시 고치고 싶으면 [다시 고치러 가기]를 누르세요.

> 만든 노래는 하루(24시간)가 지나면 이 사이트에서 지워져요. 그 전에 저장해 주세요.

## ⓪ 로그인 (`Login.html`, 6단계)

**제목**: 로그인하는 방법

1. 관리자에게 받은 **아이디**와 **비밀번호**를 넣어요.
2. 비밀번호가 잘 보이지 않으면 [비밀번호 보이기]를 눌러 확인하세요.
3. [로그인]을 누르세요. 이 컴퓨터에서는 한 달 동안 다시 로그인하지 않아도 돼요.
4. 다 쓰고 나서 다른 사람과 함께 쓰는 컴퓨터라면 맨 위 [나가기]를 눌러 주세요.

> 아이디나 비밀번호를 잊어버렸으면 관리자에게 물어보세요.

## "저장한 노래는 어디서 찾나요?" (⑦ 링크)

**제목**: 저장한 노래 찾기

1. 저장한 노래는 컴퓨터의 **다운로드** 폴더에 있어요.
2. 크롬이나 엣지에서는 키보드의 **Ctrl** 키와 **J** 키를 함께 누르면 받은 파일 목록이 보여요. (맥은 **⌘** 키와 **Option** 키와 **L** 키)
3. 파일 이름은 "내 노래_월일.mp3"예요. 예: 내 노래_1011.mp3

## ① "유튜브 주소는 어디서 찾나요?" 그림 3장

와이어프레임의 `[화면 그림 1~3]` 자리에 들어갈 그림. 실제 유튜브 화면 캡처 · 로고는 쓰지 않고 **단순한 그림(SVG)** 으로 그린다 (상표 · 저작권 문제 방지).

| 그림 | 내용 | 아래 글 (와이어프레임 그대로) |
|---|---|---|
| 1 | 브라우저 창 안에 동영상 화면(재생 단추 모양)이 있는 그림 | 1. 유튜브에서 노래 영상을 열어요 |
| 2 | 같은 창의 맨 위 주소창이 파란 테두리로 강조되고 손가락(마우스 화살표)이 가리키는 그림 | 2. 맨 위 주소창을 한 번 눌러요 |
| 3 | 주소창 위에 오른쪽 클릭 메뉴가 뜨고 [복사] 칸이 강조된 그림 | 3. 마우스 오른쪽 → [복사] |
